### Smart Price Calculation
```typescript
// Before: Simple fallback (wrong when price = 0)
const price = variant.price || basePrice

// After: Proper handling
const price = getVariantPrice(variant, basePrice)
const hasOverride = hasVariantPriceOverride(variant, basePrice)
```

### Reusable Variant Selector
```tsx

  groupName="Color"
  allValues={["Red", "Blue"]}
```
