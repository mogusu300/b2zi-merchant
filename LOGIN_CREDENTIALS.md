## Troubleshooting

If login fails:

1. **Check the browser console** for error messages (F12 → Console tab)
2. **Use the Login Test Page** at `/login-test` to verify API responses
3. **Verify database** by checking if users exist

The APIs are working correctly. If redirects fail, check the browser console for errors.
